## Facts measured tonight that the code now depends on

- Claude Code's footer string "esc to interrupt" is truncated by narrow
  panes; the spinner line ("Seasoning… (17m 10s") is the reliable busy sign.
- "bypass permissions on" is ALWAYS on a Claude pane's screen, so READY
  after `/clear` proves nothing; the session id rotating in
  `~/.claude/sessions/<pid>.json` is the only proof a clear ran.
- Two Ctrl-C into a busy Claude pane interrupt the turn and DROP its queued
  messages; they do not exit. `/exit` queues, then asks "Exit and stop
  tasks / Stay". `#{pane_current_command}` for a Claude pane is its version
  string ("2.1.270"). `tmux respawn-pane -k` is the reliable way to replace
  a pane's process and keep the pane id.
- Under load, a fresh zsh can sit minutes in its `mise hook-env` prompt hook;
  anything typed before the prompt waits in the buffer.
- Codex truncates its composer placeholder to the pane width ("Ask Codex to
  do anyt"); the ready marker is now the prefix "Ask Codex".
- A client attached at 92 or 104 columns shrinks every pane of a 240-wide
  rig. `window-size manual` pins it, but only when the window is built.
- Rohan types into pane composers and does not always press Enter; a draft
  left in a composer turns the next `/clear` into a message (hence Ctrl-U).
- Claude Code writes a `cost-state` record per session transcript with
  `totalCostUSD` and per-model usage. The weekly meter is read from
  `https://api.anthropic.com/api/oauth/usage` with the OAuth token in the
  Keychain item "Claude Code-credentials" (`weekly_all` and a separate
  Fable-scoped limit). Tonight's two tasks: $25 list price, about a fifth of
  it checkpoint mechanics.
- 100K is too small an Opus ceiling on a Swift codebase: five resets on one
  task. 140K on both builders finished GOAL-01 with no cycle at all.
- A Claude pane's SessionStart hook (`~/.lifeos/bin/claude_fleet_hook.py`)
